# QuickBlog

A MERN blogging platform where users write blogs (with AI help) and the admin approves them.

**Live:** https://quick-blog-nine-phi.vercel.app

The backend uses a free plan, so the first load may take up to a minute.

## Features

- Sign up, login, and write blogs
- AI blog generation from a title
- Admin approves or rejects blogs
- Comments, search, and categories

## Tech Stack

React, Vite, Tailwind, Node.js, Express, MongoDB, Cloudinary, Gemini API
